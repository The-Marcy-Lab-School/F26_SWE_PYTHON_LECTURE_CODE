# 1.8 Dictionaries

Every file in this folder works on the same café receipt and menu from the lesson. Run any file with `python3`, for example:

```sh
python3 01_records.py
```

The files follow the lesson in order:

| File | Lesson section |
| --- | --- |
| `01_records.py` | Dictionaries: From Rows to Records, and Records: One Thing's Information Together (through Challenge: Updating a Receipt) |
| `02_receipt.py` | Lists of Dictionaries (the receipt program) |
| `03_menu_order.py` | Lookup Tables, and Looking Up a Key Held in a Variable |
| `04_add_to_menu.py` | Challenge: Dynamic Keys |
| `05_iterating_and_counting.py` | Iterating Over Keys and Values of a Dictionary, and Challenge: Counting Items |
| `06_references_and_copying.py` | Dictionaries are Mutable and Held by Reference, and Advanced Topics |

`02_receipt.py`, `03_menu_order.py`, and `04_add_to_menu.py` ask for input, so they run as they are.

The other files start with code that runs as it is. Below it, the rest of the file is commented out in sections named after the lesson's headings. As the lesson goes on, uncomment one section at a time and run the file again. In VS Code, select the whole section, from its `# # ----------` heading to its last line, and press `Command+/` (`Ctrl+/` on Windows). The headings and explanations are commented twice, so they stay comments while the code becomes runnable.

Some sections ask you to predict the output before you run them, so read the comment at the top of each section first. A few sections end with a line that crashes on purpose. Uncomment it to see the error, then comment it out again so the rest of the file still runs.
