# 1.7 Lists

Run any file from this folder with `python3`, for example:

```sh
python3 02_receipt.py
```

Each file matches one example or exercise in the lesson, in the order the lesson presents them. Some files ask you to predict the output before you run them, so read the comment at the top of the file first. Some files ask you to type something when you run them, so watch the Terminal for a question.
