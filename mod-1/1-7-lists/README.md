# 1.7 Lists

Every file in this folder works on the same receipt from the lesson. Run any file with `python3`, for example:

```sh
python3 01_receipt.py
```

Each file runs as it is. Below the first part, the file is divided into sections named after the lesson's headings. In each section, the definitions and other lines that print nothing are already uncommented, so they run without changing the file's output. The lines that print are commented out. As the lesson goes on, uncomment one section's printing lines at a time and run the file again. In VS Code, select only the commented lines of code in that section and press `Command+/` (`Ctrl+/` on Windows). A selection that includes an uncommented line comments every line instead, so leave the uncommented lines out of the selection. Leave the section's heading and explanations out of the selection too, because they are commented only once and would become lines that Python cannot run.

Some sections ask you to predict the output before you run them, so read the comment at the top of each section first. A few sections end with a line that crashes on purpose. Uncomment it to see the error, then comment it out again so the rest of the file still runs.
