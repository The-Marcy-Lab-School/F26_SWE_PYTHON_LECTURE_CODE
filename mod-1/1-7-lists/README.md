# 1.7 Lists

Every file in this folder works on the same receipt from the lesson. Run any file with `python3`, for example:

```sh
python3 01_receipt.py
```

Each file starts with code that runs as it is. Below it, the rest of the file is commented out in sections named after the lesson's headings. As the lesson goes on, uncomment one section at a time and run the file again. In VS Code, select the lines and press `Command+/` (`Ctrl+/` on Windows) to uncomment them.

Some sections ask you to predict the output before you run them, so read the comment at the top of each section first. A few sections end with a line that crashes on purpose. Uncomment it to see the error, then comment it out again so the rest of the file still runs.
