# 1.6 Loops

Run any file from this folder with `python3`, for example:

```sh
python3 01_vowels_without_a_loop.py
```

Each file matches one example or exercise in the lesson, in the order the lesson presents them. Some files ask you to predict the output before you run them, so read the comment at the top of the file first. Many files ask you to type something when you run them, so watch the Terminal for a question.

If a program never stops, press `Control+C` in the Terminal to stop it.
